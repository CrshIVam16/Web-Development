# 📝 TODO App

A simple and clean to-do list application built with HTML, CSS, and JavaScript.

## Features

- Add new tasks to your to-do list
- Mark tasks as completed with a checkbox
- Remove individual tasks
- Clear all tasks at once
- Save tasks in the browser using localStorage so they remain after refresh

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Open the project folder in your browser.
2. Launch the file named `index.html`.
3. Start adding your tasks.
4. [live-link](https://cr-todo.netlify.app/)

## Project Structure

- `index.html` — Main structure of the app
- `style.css` — Styling for the UI
- `index.js` — Logic for adding, removing, and saving tasks

## Usage

- Type a task in the input box and click **Add TODO** or press **Enter**.
- Use the checkbox to mark a task as done.
- Click **Clear** to remove a single task.
- Click **Clear All** to remove everything.
