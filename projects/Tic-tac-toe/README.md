# Tic-Tac-Toe

A simple browser-based Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

## Features
- Two-player gameplay
- Turn-based X and O switching
- Winner detection for all standard winning combinations
- Draw detection when the board is full
- Reset button to start a new round

## Project Files
- [index.html](index.html) — Main game layout
- [style.css](style.css) — Styling for the board and UI
- [script.js](script.js) — Game logic, win/draw detection, and reset behavior
- Hosted demo: [live-link](https://cr-tic-tac-toe.netlify.app/)

## How to Run
1. Open [index.html](index.html) in your browser, or
2. Serve the folder with a simple local server if you prefer.

## Gameplay
- Click any empty box to place your mark.
- Players alternate between X and O.
- The game announces the winner or a draw automatically.
- Use the Reset button to begin again.
