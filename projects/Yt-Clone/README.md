# YouTube Clone

A static YouTube landing page clone built with HTML and CSS. This project recreates the YouTube Premium promotional layout with a responsive navigation bar, feature highlights, and FAQ section.

## Features

- Sticky top navigation with search input and icons
- YouTube Premium promo section with pricing and call-to-action
- Features cards for ad-free playback, downloads, and YouTube Music
- Full-width promotional sections with background images
- FAQ section with question layout and help center link

## Live Demo

- Local preview: open `index.html` in your browser
- Hosted demo: [live-link](https://cr-yt-cloned.netlify.app/)

## Usage

1. Open the `Yt-Clone` folder.
2. Open `index.html` in a web browser.
3. Keep the `style.css` and `assets/` folder in place for correct styling and images.

## Files

- `index.html` - main webpage structure
- `style.css` - page styles and layout rules
- `assets/` - icons and background images used by the page

## Notes

This is a front-end only project without JavaScript interactivity. It is ideal for showcasing static UI design and layout skills.
