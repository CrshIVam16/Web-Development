# Sneaker Store

A simple static sneaker showcase built with HTML and CSS. This project displays multiple sneaker cards with images, product details, and shopping cart icons in a clean responsive layout.

## Features

- Product card layout with sneaker images
- Shoe details including model, gender, colour options, and price
- Cart icon for each product card
- Clean, mobile-friendly UI powered by `style.css`

## Live Demo

- Local preview: open `index.html` in your browser
- Hosted demo: [live-link](https://cr-sneaker-store-cloned.netlify.app/)

## Usage

1. Clone or download the project folder.
2. Open `index.html` in a web browser.

## Files

- `index.html` - main page structure
- `style.css` - styling for the shop layout
- `images/` - sneaker images and icons used in the storefront

## Notes

This is a front-end only project with no backend or JavaScript logic. It is ideal for portfolio display or practice building static landing pages.
