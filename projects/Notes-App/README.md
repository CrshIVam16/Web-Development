# 📋Notes App

A simple and lightweight notes application built with HTML, CSS, and JavaScript. This project lets you create, edit, and delete notes directly in your browser, with notes saved locally using browser storage so they remain available after refresh.

## Features

- Add new notes instantly
- Edit existing notes in place
- Remove notes when they are no longer needed
- Save notes locally in the browser
- Display the time each note was created or updated
- Render note content using Markdown-style formatting

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Marked.js for Markdown rendering

## Project Structure

- [index.html](index.html) – Main structure of the app
- [style.css](style.css) – Styling and responsive layout
- [index.js](index.js) – Note logic, editing, deletion, and local storage handling
- [Live-link](https://cr-notes-app.netlify.app/)

## How to Run

1. Open [index.html](index.html) in your browser.
2. Click the "Add Note" button to create a new note.
3. Use the "Edit" button to modify a note and the "Remove" button to delete it.
4. Refresh the page to confirm that your notes are still saved.

## Notes

- Notes are stored in the browser using local storage.
- This is a front-end-only project and does not require a backend or database.
- For a smoother development experience, you can open the project with a live server extension in your editor.
