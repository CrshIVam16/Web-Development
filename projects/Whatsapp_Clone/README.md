# WhatsApp Clone

A static WhatsApp landing page clone built with HTML and CSS. This project recreates a polished WhatsApp-style marketing page with sections for features, calls-to-action, privacy, and business messaging.

## Features

- Responsive hero section with download button
- Navigation menu and sticky header layout
- Multiple feature sections showcasing private messaging, calls, groups, and business tools
- Animated image elements and modern section styling
- Uses local assets from the `whatsApp/` folder

## Live Demo

- Local preview: open `index.html` in your browser
- Hosted demo: [live-link](https://cr-whats-app-cloned.netlify.app/)

## Usage

1. Open the `Whatsapp_Clone` folder.
2. Open `index.html` in a web browser.
3. Ensure the `style.css` and `whatsApp/` asset folder are present for correct styling and images.

## Files

- `index.html` - project structure and content
- `style.css` - styling and layout rules
- `whatsApp/` - image assets used by the page

## Notes

This is a front-end only project with no JavaScript logic or backend integration. It is ideal for portfolio display and UI practice.
