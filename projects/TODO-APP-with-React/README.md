# 📝TODO APP with React

A small TODO application built with React and Vite. Use this project as a starter for learning React, experimenting with state management, and building a lightweight frontend app.

Key features

- Add new todos
- Delete todos
- Persist todos in `localStorage`

Tech stack

- React
- Vite (dev server + build)
- Tailwind CSS (optional, included in dependencies)
- react-icons

Getting started

Prerequisites: Node.js (LTS) and npm or yarn.

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Project structure

- `index.html` — app entry
- `src/` — React source files (`main.jsx`, `App.jsx`, styles and assets)
- `public/` — static assets
- [live-link](https://cr-todo-via-react.netlify.app/)

Notes

- The app persists todos to `localStorage` so they survive page reloads.
- Tailwind is listed in `package.json`; if you're not using it, remove the dependency or configure it in `tailwind.config.js`.
