# Paytm Clone

A static Paytm landing page clone built with HTML and Tailwind-style classes using plain CSS. This project recreates a Paytm-style UI for payments, banking, business services, and financial products.

## Features

- Responsive Paytm-style navigation bar and hero section
- Recharge and bill payment cards with service icons
- Promotional banners for app download, bank payments, credit cards, insurance, and investments
- Business payment and Paytm Money sections
- Footer with links and social icons

## Live Demo

- Local preview: open `index.html` in your browser
- Hosted demo: [live-link](https://cr-patym-clone.netlify.app/)

## Usage

This project uses Tailwind CSS through Vite, so you should run it with Node.js instead of opening `index.html` directly.

1. Install Node.js if needed.
2. Open the `Patym_Clone` folder in a terminal.
3. Run:

```bash
npm i vite [to install node_modules via vite]
npm run dev [to start the server]
```

4. Open the local URL shown in the terminal, usually `http://localhost:5173`.
5. Keep `style.css` and the `assets/` folder in place for correct styling and images.

## Files

- `index.html` - main page structure and content
- `style.css` - styling and layout rules
- `assets/` - images, icons, and visual assets used by the clone

## Notes

This is a front-end only project without backend or JavaScript interactions. It is best used as a UI/UX portfolio project to demonstrate static landing page design.
